Each run is one scrape of one product at one vendor. Open a run to see what it found, what it dropped and what changed since the run before it.

What the statuses mean
queued
Assembled and XADD-ed to the Redis stream. It stays here until a worker in the workers consumer group picks it up. If no worker is running it will sit here forever — the orchestrator does not time queued jobs out. Use Cancel / Purge queue below.
ok / partial / error
A worker finished the scrape and POSTed a result to the ingest endpoint. partial = some selectors failed or a challenge page was hit but listings were still extracted; error = the scrape or delivery failed.
dead
A worker gave up on the job: its payload was malformed, or it exceeded MAX_ATTEMPTS reclaim cycles (a worker kept claiming it and never delivered a result). The worker moves it to the scrape.jobs.deadletter stream and the reconcile loop flips this row to dead. This is not set just because a job is slow or stuck queued.
canceled
You removed it from the queue via Cancel or Purge queue.
